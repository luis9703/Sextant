# Frame

- User seed: “现在我抛出一个问题，当AI大模型及其相关工具如此强大之后，像office、WPS这样子的软件还会有市场需求吗，尤其是现在大家都在用HTML格式去进行信息的传递和呈现。”
- Intent: explore plausible futures and changing demand, not give a product-stock or vendor-survival verdict.
- Scope chosen: office productivity suites and their adjacent ecosystems (Word/Excel/PowerPoint-like authoring, collaboration, storage, workflow, compatibility, governance); global framing with Chinese-language users as a salient but not exclusive context.
- Horizon: near-to-medium and longer-range branches, described relatively because no forecast resolution date is supplied.
- Profile: deep. Token target from frozen profile is 50k–100k as a planning envelope, not measured usage or quota; actual telemetry unavailable (unknown).
- Resources: public web search and opened primary/official sources; isolated context for the requested first six phases. No expert interviews or market-size dataset supplied.
- Key ambiguity: “大家都在用HTML” is an observation, not yet independently established; HTML is a delivery/presentation format and may coexist with authoring, calculation, review, compliance and archival formats. “市场需求” may mean user need, active use, willingness to pay, vendor revenue, or value capture; keep these separate.
- Process boundary: complete frame through pathways, then make neutral review packet; do not perform review/reconciliation/delivery in this host turn.
