# Factual foothold (cutoff 2026-10-02)

## Claims currently supportable

- Microsoft describes Microsoft 365 as including desktop/web/mobile Office apps plus cloud services and collaboration; this is a vendor product description, not evidence of demand or future resilience. Source F1.
- Google Workspace help documents editing Office files in Docs, Sheets and Slides, with Office format compatibility and conversion options. This supports coexistence and interoperability as an existing product direction, not universal compatibility. Source F2.
- W3C describes HTML as the standard markup language for structuring web content. It does not itself provide spreadsheet formulas, document semantics, permissions, audit trails, or a complete enterprise workflow. Source F3.
- Microsoft Office Open XML is a documented family of XML-based formats for word-processing, spreadsheet and presentation documents. File format and app are distinct layers. Source F4.
- Microsoft 365 Copilot is presented as embedded across Word, Excel, PowerPoint, Outlook and other apps. This establishes vendor strategy and capability availability claims only; it does not prove quality, adoption or willingness to pay. Source F5.

## Unverified/ambiguous

- “Everyone is using HTML”: not supported as a quantified population claim. It may refer to web-first sharing of reports, dashboards, newsletters or AI-generated pages.
- “AI tools are so powerful”: directionally plausible but underspecified by task, quality, reliability, permissions and cost. Treat capabilities as uneven and improving conditionally.
- Market demand: separate need/use, paid seat or subscription, indirect monetization, and provider value capture. No current market-size number is needed for the exploration.

## Source notes

F1. Microsoft, “Microsoft 365 for individuals,” https://www.microsoft.com/en-us/microsoft-365 (accessed 2026-10-02). Official product page; establishes bundle surface only.
F2. Google Workspace Learning Center, “Use Office editing mode and work with Office files,” https://support.google.com/docs/answer/6055139 (accessed 2026-10-02). Official help; establishes supported workflow, not fidelity across all files.
F3. W3C, “HTML: HyperText Markup Language,” https://developer.mozilla.org/en-US/docs/Web/HTML (accessed 2026-10-02), MDN reference; defines HTML's web-content role, not a market measure.
F4. ECMA International, “Office Open XML File Formats,” https://ecma-international.org/publications-and-standards/standards/ecma-376/ (accessed 2026-10-02). Standards publisher page; identifies standardized document formats.
F5. Microsoft, “Copilot in Microsoft 365 apps,” https://www.microsoft.com/en-us/microsoft-365/copilot (accessed 2026-10-02). Official product description; claims need independent adoption/quality evidence.
