# 资格循环失败之后：流动与留下的政治

暂时假设：社会越来越称赞主动换职业，学费补助较易取得，但带薪实践、导师和真实招聘没有同步扩大；雇主仍偏好已经做过该行业的人。此是条件组合，S4提示认可缺口，不证明当前所有雇主/培训者如此。

**第一次：更新叙事先出现。** 虚构场景：客服周檬想改善作息，得到一张学习券，学数据处理并完成项目。她求职时被要求业内经验。课程方没有承诺保证就业，确实教授了能力；但学习券只解决课费，雇主没有实践名额。她留在客服岗位，晚上继续制作作品。

**第二次：失败被重新包装。** 数年后新工具改变任务，周檬看到更高级证书被用作筛选。她既怕过去投入白费，也希望不再上夜班，于是再次学习。有家庭缓冲的同学可接受低薪实践，通过关系取得推荐；她不能。这种分化不必由坏培训或假证书产生，真实技能也会因入口稀缺无法兑换想要的生活。若雇主追逐更新的证明，她更难把所学兑现；若岗位真的扩张且允许在岗实践，她也可能成功，D并非注定。

**新欲望与结盟。** 几位同事在不同转型尝试后交流，发现他们想改变的核心都是无法预测的工时和没有任务决定权。他们不再以成功离开人数衡量学习；有的人确实离开并提供外部实践信息，有的人留下来提出客服排班和培训时段调整。他们请求试一个固定班组，而不是共同购买下一张证书。比较经验使“其他单位怎样组织工作”成为谈判材料，失败没有自动产生议价力量。

**有条件的留下路线。** 若管理者愿试/员工有谈判渠道，并且客户需求允许稳定班表，班组用新数据能力观察忙闲，再约定自主换班和有薪学习时段。改变的是工作权与共同协调，学习是手段。随后新员工不再先买证书才获信任，而能在工作中轮换低风险任务；资深人员把教学写入工时。周檬仍可选择离开，但此时留下不是失去勇气，而是已有比较后愿意保留本地关系。

**普通事件再次反馈。** 一次需求高峰要求临时夜班，暴露谁承担改善代价。若只让没有子女的人补所有夜班，留下路线会制造新不公平；需要公开轮值、额外报酬或真实拒绝权。班组若不掌握足够人手/收益，稳定班表可能根本做不到，必须缩小承诺。若管理者只用“成长岗位”重命名客服而不改变时间，员工会退出协商并重新寻求外部流动，或与其它班组争取规则。

**更广的公共冲突。** 已付税却未使用学习券的稳定工作者可能质疑为何资金一直给报名，而非让熟练者有时间带新人。转型者则要求把公共支持扩展到实践入口、照护和回归。政治争论从“谁应更努力学习”移向“谁应承担转换成本”，但没有保证争论形成改革。有些人可能反而支持收紧补贴，认为失败者在浪费；这是同一失败的相反反馈。

**回到现在。** 先观察课程参与增长与真实转型脱节→通过具体经历识别瓶颈是认可/时间/岗位，而不是自动归咎能力→有在岗协调与谈判入口才产生E→再经历需求高峰，才检验新规则是否持续。没有把培训失败直接推成政治觉醒，没有以某个现实国家示范保证普适。

**社会变化。** 在D占主导的局部，人生故事成为雇用过滤器，空档可被富人讲为探索、被穷人解释为不稳定。在E能发展处，尊重的对象包含跨界者、返回者和改造一处生活的人；稳定不再等于没有学习。两者可在不同企业/社区共存。

**停止条件与剩余问题。** 若行业工作量已消失，没有可持续收入需求，班组改排班不能保存所有岗位；有些人仍必须换领域。未估算行业需求、工会效力、净成本，不给通用成功概率。下一有价值问题在群体如何得到另一种实际供给而非只谈判旧岗位，留给后续group-e5。
