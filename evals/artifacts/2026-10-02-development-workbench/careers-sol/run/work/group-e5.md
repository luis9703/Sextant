# 共同学习何时成为共同转换

输入：choices-c1显示时间/收入/照护条件不互代；failure-e3显示课程补助未必建立入口。暂时假设：一个街区有人想重新组织生活，但多数不能同时离岗；有愿付出时段的成员、合格有薪照护服务、允许共同经营的组织条件、可承受的小规模财务缓冲。没有假设各地已有这些条件或合作社必定成功；S7只证明机构已有相关工具。

**普通事件。** 一位居民准备学习照护服务协调，却因晚班与亲属照护不能去。另一位有更固定的白班，但想学习社区维修；两人约定不是“替你照护我再去成长”，而各自贡献不同的固定时段，并邀请已有照护从业者有薪指导。第一批只学习日程协调、需求沟通和维修安全边界，专业照护仍由合格人员提供。

**成员响应。** 参与者发现一个人的新职业不解决所有人的时间冲突，他们把目标改成共同获得可预测生活。少数人先接受较长训练/带薪实践，其他人维持收入和有限协调；并非每个人最后都做照护或维修。付款者可能是接受服务的家庭、公开服务资助或成员，但受照护者需能说不，不能成为课程练习的被动对象。

**第二轮转换。** 第一批成员有了更稳的工作和服务入口后，下一批得到学习时段。原来只做协调的人可能发现自己想成为长期组织者，另一个人完成训练却不喜欢直接照护，返回旧行业并提供后勤。返回者保留共同决策权但不自动拥有专业指挥权。团体靠接续服务和明确职责保留身份，降低个人转行的孤立，但也产生归属压力。

**失败与新生活。** 一次成员退出和照护需求突增，使排班无法兑现。若以情感勒索让没有正式岗位的人免费填所有空缺，团体复制C的后勤剥削。另一分支是缩减服务承诺、支付替补、让不能参加的人保留使用普通服务与独立退出权。成员意识到共同转换不等于共同创业；也可以只形成联合学习与议价安排，专业供给继续由公共/市场机构负责。

**重复后的改变。** 可行分支中，街区留下了学习—服务—再学习的循环，人的事业转换与本地服务能力相接。一部分人换岗位，一部分改变家庭分工，一部分继续深耕；共同生活的连续性由可交接责任而非固定职业提供。若资金或信任不足，只保留有限互助也有价值，不能为了“未来新制度”扩大承诺。

**回到现在。** 先有小范围具体时间需求与可见服务缺口→分批试做、接受服务者参与设计→合格人员与付费机制提供安全/连续供给→首批服务产生真实时间释放才允许下一批学习→多次验证后才可能形成地方长期组织。课费券或一本合作社手册不会跳过这些桥。

**下一稀缺。** 管理、冲突解决与专业照护的长期劳动。若成员偏好、时间和财务都不同，同伴情谊不足以协调。不能估计此路成本低于公共服务；它是有代价的替代，不是让低收入者自助解决一切。

结果：C存在个人错峰和集体生活供给两个机制，不能压成“家庭支持”。群体可以帮人转换，但群体也应允许人不再转换、不换职业或退出。
