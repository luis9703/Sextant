# 06 · 到 2038 年的条件性演化路径

**合成封闭世界；所有未来阶段、制度和人物均为推演。** 事实仅来自 [S1—S5 原始资料](../source-pack.md)。试点开始日期未知，阶段不对应预定年份；2038 年是观察终点，不是保证到达的期限。以下路径可以并存。

## P1 · 家庭拥有的可能是一段有保障的时间

**2038 年的虚构示意：** 一家人安排下周任务，争论的是哪两次取送值得占用晚间保障。有人愿意改用较宽松的白天，另一个人坚持保留晚间自由。家里未必停着自己的车。若家里有车，也不会把“车在停车位上”视为必然能出租赚钱。

**演化过程。** 当前获批运营方已经负责调度和事故，但并无家庭接入和支付条款（S3、S1）。首先，若运营方能在现有运书任务上记录并兑现一定范围的取送时间，它才有理由提供可承诺的窗口。这个前置条件是可靠的实际服务，而不是买入更多设备的数量。

下一步是把时段承诺写成可理解的使用规则：可以取消到什么时候，同峰时怎样排队，谁可保留刚性自用需求，承诺失败后怎样处理。家庭购买服务资格或共同出资，只是可能的供给安排；运营资金可以来自透明的付费或明确资助，但资料没有证明任何一种已经可持续。若另外确认允许家庭出租，家庭还需要维护、损坏、空驶和停用责任，以及完整净成本规则。某个租赁家庭没有盈利，不会逻辑上阻止运营方自有设备的服务路径。

实际采用后，一部分家庭可能自愿把弹性任务移出高峰，从而提高原有容量的匹配度；另一部分家庭的晚间需求无法移动。S5 的一个同峰例子提出了这种冲突，没有告诉我们它多普遍。若平台把灵活安排当成人人都能做到，生活被调度体系牵着走，居民会退回独用或退出。若规则允许保留少量真正需要的窗口，家庭的资产观可能从“有车才安心”转成“关键时候可调用才安心”。

多次冲突会进一步引出社区对优先权和配额的协商：谁的承诺算数，未出资者能否进入，是否允许转让。这里出现的是待建立的使用权制度，而不是已获得的财产权或经营许可证。反馈可能正向：可靠承诺带来愿意协调的使用者，协调又减少部分冲突；也可能负向：过量承诺带来囤积预约，囤积又造成名义满载和真实低利用。

**分支条件与出口。** 必要的是可兑现的任务容量、可接受的调度责任、明确支付来源和居民愿意遵循的分配规则。家庭所有权、家庭经营许可或 70/30 分账均不是整条路径的必要条件；家庭租赁支线则另需获准接入和具体合同。新的稀缺是符合家庭节奏的可靠时段。若检查确实挡住可用设备，扩张受限；若原因是空驶或同峰，则增加检查投入未必有效。

**与基线的差别。** 常规延伸只是更多人下单运书；本路径增加“可保障的使用时段”及其分配制度。最近的资料内相关设想是 S1 网评的私车分账，但此路径没有收入承诺。外部先例未研究。

## P2 · 家庭与社区共同承担一项任务，机器不必长得像家庭成员

**2038 年的虚构示意：** 一位住户把待归还的书放到双方认可的交接位置，另一位在约定时段帮忙确认。若未来另有被验证的专用服务，某类物品可以去共享任务空间处理，再送回家。住户为兼容任务调用公共能力；不适合离家的任务继续保留私人设备或人工处理。

**演化过程。** S2 只支持当前小型单件格运书。第一步可以保持这一窄能力，只改变交接：若居民、图书馆和运营方能确认谁何时接收物品，减少为每次交接等候的麻烦就有条件成立。这仍需可靠交接与失误处理的验证，不能由自动运输能力自动推出。

重复使用后，一些家庭可能愿意共用交接位置。为了让这种安排持续，必须有人提供空间、处理误放和未及时领取，考虑不能到达该位置的人，并明确保管责任。共同交接既可能节省多次等待，也可能把运营成本转给值守邻居。若净负担落到少数人，原本便利的设施会成为社区争吵来源。

更大的形态变化是条件跳跃：**只有当某一额外生活任务形成经过验证的专用处理能力、物品适合转移、责任边界也被接受时**，共享任务空间才可能承担运输之外的工作。移动单元、交接设施、专用处理设备不必装在同一台机器人里；现有小车仍只做自己能做的部分。这里没有断言清扫、做饭或照护能力已经存在，也没有说换一个格子就解决了它们。

若兼容任务确实反复替代了某些私人设备的功能，家庭才可能少买、合用或延后更换相应物件。重复可靠交接 → 愿意转移更多兼容任务 → 对共享空间投入更多维护，是可能的正反馈。反向反馈也成立：物品丢失、排队、卫生或接近性问题 → 保留私人备份 → 共享使用减少 → 单次服务更难维持。未来住宅或公共空间可能围绕交接和保管重新安排，但需要空间使用者的同意和资源，不能从车的普及直接跳到建筑必然改变。

**分支条件与出口。** 只做运书交接的低能力分支，不需要新增生活任务技术；扩展处理分支另需相应能力的验证与持续投入。两者都不要求每个家庭拥有或出租车。新的稀缺是适合的位置、可信保管、人的最后一步和可接近性。若这些条件不成立，保留直接交接或私人设备；若扩展技术迟迟没有证据，路径可停留在书籍处理，不宣称家庭全面“去资产化”。

**与基线及类比的差别。** 基线把一次任务理解为小车从甲到乙；此路径把完整服务分解为移动、交接、专用处理及家庭剩余工作。结构类比是分工系统中不同环节各用适合资源，断点在于移动兼容不保证处理兼容，也不保证交接无成本。该类比只是设计推理，没有引入外部案例。

## P3 · 相遇变成居民能够主动选择的生活部分

**2038 年的虚构示意：** 一位居民平日让车送书，另一天去有人的共同取书活动。邻居只想收书而不参加；两者都能继续使用相应服务。另一组住户更喜欢轮流互助取送，让机器只接手大家同意的外围任务。

**演化过程。** S5 的小样本同时出现少做杂务的满足与想念工作人员的体验，不能推成全镇共识。若运送增多，一些与取书顺带发生的接触可能减少。居民此时有不同回应：享受不必见人，主动寻找新的见面理由，或者把便利的损失视为值得付的代价。

愿意保留相遇的人可以提出有边界的安排：某些时段仍由工作人员或自愿居民接待，把取书与交流结合；其他时段继续运送。安排成立要有参与者真实到场、人员与场地资源、可持续的承担方式。资料没有给出资金来源，不能假定图书馆会无偿增加工作，也不能用机器人利润支付一切。

若共同活动持续，参与者可能开始为选书、结伴和照应而来；取送从不得不做的事务转为共同参与的入口。使用便利后的欲望也可能改变：有人更珍惜主动安排的见面，有人更重视摆脱义务式寒暄。相遇网络由活动反馈加深，也可能只留下彼此熟悉的一小群人，使后来者或不愿公开行踪的人感到被排斥。

** materially 不同的反向路线：** 如果居民认为正式服务破坏互惠，一小群人可以先约定互相取送；反复承诺逐渐变成轮值和补位规则，机器只在成员明确同意时协助。共同承担可能增进关系，也可能把人情债与劳动压到少数人。出现无法补位、照顾负担偏斜或退出困难时，互助网络可能缩小为自愿小组，转用混合服务，或解散。拒绝机器不是无成本的道德优越路线。

**分支条件与出口。** 必要的是部分居民愿意投入接触、有人承担接待与空间、服务规则允许不同偏好并存；不要求全镇偏好一致，不要求私人车分账，也不要求新机器人形态。新的稀缺是可信且可退出的共同时间。若只有“参加活动才能拿到书”，关系选择变为义务，此候选的自主接触机制失败。若到访下降只是活动时段不便，不能立即解释为居民不再需要联系。

**与基线的差别。** 基线优化运送；此路径把实用任务与社交接触拆开，让它们可选择地重新组合。最近资料依据是 S5 两种体验，既未证明活动可持续，也未证明未来互助扩散。

## P4 · 家庭中“谁去办”转成“谁能自己决定”

**2038 年的虚构示意：** 一位原来总请家人取书的成员，在自己的可用额度与接受的规则内发起取送。家里不再为了这次跑腿重新排班，却开始讨论本人请求能否被随意取消，以及处理异常的劳动由谁承担。这是特定家庭的假设，不是关于老人、儿童或所有被照护者的事实判断。

**演化过程。** 现有材料只告诉我们部分用户喜欢避免杂务，没有说明便利由谁享有（S5）。若获批运营方的任务请求方式能被本人理解和使用，授权清楚、费用可承担，某位原来依赖他人跑腿的家庭成员才可能独立发起有限的运书任务。该变化可以利用狭窄能力，不需要机器人进入家里或承担照护。

最初家庭可能仍由熟悉服务的人帮忙安排；几次可靠完成后，被代办者可能希望决定选什么书、什么时候送，协调者也可能希望减少随叫随到。这会把分工谈判转到规则：哪些请求由本人决定，谁付款，能否撤回帮助，意外时谁跟进。若程序不清楚，跑腿劳动可能只是变成提醒、下单、追踪和投诉等不可见工作。

如果家庭确实给予实质选择，某个人会从“接受照顾的人”转向“能安排一部分日常的人”。通过使用而形成的自信与偏好可能带来更多自主请求，社区也可能开始要求服务资格能够落实到个人而非只认某个家庭控制者。这是从具体使用冲突生长出的制度假说；不能把它写成 R 镇已确立的个人服务权。

也可能出现相反反馈：掌握付款或预约资格的人控制更多决定；服务越方便，其他成员越少练习独立安排，依赖反而集中。若本人不想直接操作或能力不适配，可信代理仍可能有价值，前提是其授权范围和退出方式被接受。把“让所有人独立下单”设为统一目标，会再次抹去人的选择。

**分支条件与出口。** 必要条件是针对本人可用的请求和授权方式、可负担的有限任务、基本可靠性以及家庭对其选择的实际尊重。可以用运营方资产、共享时段或家庭资产完成，不依赖具体分账。新的稀缺是被尊重的决定权、故障跟进能力和可负担资格。若只能由原控制者全程决定，则仍可能少跑腿，但不应称为自主性增加；若协助需求上升，则保留有人代理的混合路径。

**与基线的差别。** 基线用订单量和省时描述服务；此路径追踪发起权、取消权和协调劳动如何改变家庭关系。其关于家庭内部权力的事实支持不足，是明确的条件性新探索，不是已发现的试点趋势。

## 约束不能在路径之间误传

| 条件类别 | 对本次路径的作用 |
| --- | --- |
| 当前产品限制：小型单件格、运书 | 约束当前能承诺的任务。P2 的额外任务处理需新的能力证据；不构成所有未来设计的尺寸定律。P1、P3、P4 可从同类运书任务启动。 |
| 可改变但尚未给出的制度：家庭租赁、支付、服务优先权、共享空间责任 | 只能作为各自分支的条件。家庭租赁尚未约定不能否决运营方资产服务；获批运营责任也不等于家家必须获批自营。 |
| 逻辑与资源限制 | 同一资源不能同时兑现不相容的占用承诺；交接、人员、空间和异常处理需要承担者。这不要求推断未来具体成本。 |
| 未知的现实运营限制 | 检查、可靠性、需求匹配、空驶可能分别或共同限制服务。S4 不足以确认谁是瓶颈，不给每条路径预设统一解除条件。 |
