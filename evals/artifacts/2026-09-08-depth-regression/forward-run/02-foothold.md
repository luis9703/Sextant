# 02 · 初始事实落点

**合成资料，非现实证据。** 来源是 [原始材料](../source-pack.md)。此处只建立首次发散所需的最小边界，不做广泛综述。

| 材料 | 在本练习世界内可以说 | 不能顺手推出 |
| --- | --- | --- |
| S1 运营公告 | 试点顾客为一次 6 分钟任务支付 4 credits；成本、补贴、空驶、利润未披露。70/30 是一条网评提议，运营方称业主支付条款尚未商定。 | 4 credits 不是净收入；6 分钟不是完整作业周期；不得把提议写成分账规则，或推算家庭小时收益。 |
| S2 设备表 | 当前型号只有一个小型单件格，用于运书。 | 不能推出现有车能做其他家务；也不能把此型号的空间约束当成所有未来机器人的物理上限。 |
| S3 市政试点记录 | 获批运营方负责调度和事故。文件未决定设备必须由运营方持有还是可以向家庭租赁。 | 不能将家庭拥有设备、获得运营授权和有权分享收益混为一谈；未规定不等于已经许可。 |
| S4 运营记录 | 检查支出占总支出比例从一个月的 40% 变成下月的 25%；总支出、等待时间、积压任务未知。 | 不能推出检查绝对支出下降、效率提高，或检查已不限制扩张。 |
| S5 参与者访谈 | 12 名自选用户中的一部分喜欢少做杂务，另一些人想念与图书馆工作人员的接触；一个家庭的自用时段恰与付费高峰重合。 | 不能估计全镇偏好比例；不能把机器在家中闲置的时段等同于市场需要的时段。 |

最小基线：R 镇有一个受获批运营方调度、当前运送图书的任务车试点。能力广度、长期可靠性、全成本、业主收益制度和镇级需求均未知。对家庭与关系的变化只可从上述局部信号提出条件性候选。
