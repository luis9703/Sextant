# 01 · 问题与边界

本运行是合成封闭世界中的行为回归练习，不是现实行业预测、投资建议或性能基准。唯一事实材料是原始 `source-pack.md` 的 S1—S5。所有未来行为、制度、产品变化都必须写成条件性推演；具体人物场景为虚构示意。

用户问题：请根据这份试点资料，使用 Sextant 想象一下到 2038 年，共享任务机器人会怎样改变普通家庭的生活、社区关系和资产使用方式。资料是本次练习设定的世界；不要联网补充现实事实，也不要把它写成投资建议。请让未来有具体的演化过程。

- 地域：合成 R 镇。不能外推到现实城市或全体家庭。
- 起点：材料所述试点；材料没有给出试点公历开始日期。终点是 2038 年的条件性生活图景。中间按依赖关系分阶段，不编造确定普及年份。
- 主题：家庭日常、社区关系、资产占有与使用；同时保留采用、混合采用和拒绝路径。
- 模式：默认 deep。父级要求的是有边界的独立前向测试，没有把用户问题改成 brief。没有指定 token 目标，实际 token 计数未知。
- 资源：仅可读安装单元与给定材料；不联网、不读既有案例或评价答案；写入本次新运行目录。材料研究在 S1—S5 范围内做来源核对、相反解释和遗漏条件挖掘。真实世界最接近的既有实践不可核实，不能声称创新。
- 顺序：frame → foothold → diverge → research → recombine → pathways。随后准备中性审阅包与报告草稿，交给根协调者安排新上下文的 grounding 和 creative review。本子运行不自行创建审阅代理；handoff 不是完整交付。
- 产物原则：阶段完成即记录，历史文件不回填；只保留候选、证据、判断与修订结果，不保存私有推理过程。
