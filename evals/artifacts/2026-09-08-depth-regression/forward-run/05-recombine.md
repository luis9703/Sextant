# 05 · 研究后的第二次创造

**合成情景，未验证未来。** 此阶段保留首次候选，不重写其历史。下面的候选没有概率和名次；研究不仅删去了不成立的收益故事，也改变了要想象的家庭生活和制度。

## C1：家庭争取的是可保留的晚间任务窗口

研究触发：S5 的一个同峰家庭与 S3 的责任／产权分离。由 D1 的“闲置资产赚钱”和 D4 的“共享资格”转成新机制：家庭可以在合约中保留某些自用时间，把其他可用时段交给获批运营方；或者根本不购置设备，只获得有边界的任务预约权。使用权承诺需要真实可兑现容量，不是把“租车”换个名字。

新的生活后果：家庭开始讨论哪项任务值得占用晚间保障，而不是只有买不买车。若居民可自愿换用非高峰时段，部分生活节奏会跟着变化；如果调度压力强迫所有家庭迁就系统，则“省事”可能变为失去生活自主。新稀缺是与自己生活相配的可靠时段。

保留的分叉：运营方自有设备、明确允许的家庭出租、共同出资供给都可成为物理来源，条件不同。没有家庭分账规则不等于整个共享服务不能成立。现金收益不作为此候选的必要前提。

## C2：任务在社区边界拆开，家里不再需要一台全能机器

研究触发：S2 只证明狭窄运输能力，而 S3 已把协调与事故责任集中在获批运营方。由 D5 的“更大的车／更换模块”改成另一种结构：让移动、交接和专用处理分别由适合的设施承担。先从书籍边界交接发展；若以后某类额外生活任务有经验证的专用处理能力，再把它放在社区共享任务空间，而不是硬把现有小车升级为会一切家务的家庭成员。

新的生活后果：家庭从“拥有每种完整设备”走向“保留个人物品和决定权，调用社区处理能力”。真正变化的可能是玄关、共享空间的规则、交接责任和家务准备方式。住户需要准备、分类和确认物品，新的劳动未必减少。即使新任务能力没有出现，低能力的运书交接分支仍可独立存在。

新稀缺是可靠交接、空间、可追责的物品保管和不同住户可接近性。它不依赖每家能出租机器人，也不证明共享设施必然经济可行。

## C3：居民可以把运送和相遇分开选择

研究触发：S5 中“少做杂务”与“想念人”并存。由 D3 的“保留人工网点”变成双向编排：一部分往返由机器处理，但居民可选择一段有人的共同取书或交流时间；也可以只接收运送而不参与社交。实用任务提供相遇的理由，相遇无需由每次繁琐往返强制获得。

新的生活后果：图书馆或交接点可能从偶然碰面的地方，转为居民愿意专门参加的共同活动。相反，如果无人愿意承担到场与接待，共同活动会萎缩；若必须参加活动才获得服务，则它会排斥拒绝社交的人。保留第三个更不同的出口：部分居民采用人际互助取送，让机器只做外围、经过同意的环节。

新增欲望假说：一些人使用便利后可能更珍惜可选择的见面；另一些人发现远离义务式寒暄更舒服。没有材料说明哪一群更大。

## C4：不必再“求人”，但要争取自己发起任务的权利

研究触发：S5 对免去杂务的偏好不能说明谁享有便利，S3 则强调控制调度的责任主体。首轮 D2 只追问省时和分工；第二轮新增候选是家庭内部权力变化：若某位家庭成员原本需要他人代为取书，共享服务可能让其独立安排一部分日常。所需不一定是新机器人形态，而是本人能表达请求、授权被接受、可负担且不被别的家庭成员全面控制。

新的生活后果：家庭的负担从“谁去跑腿”部分转向“谁有资格下单、何时可以拒绝、谁承担费用与异常”。最早被服务的一方可能成为协调者，另一方可能开始要求自己的请求不被当作可取消的附属任务。若规则给了个人实质选择，关系会改变；若控制者只把跑腿换成代管服务，依赖形式变了而自主性没有增加。

这是一条新的人际机制，不是把所有家庭都写成追求效率。材料没有被照护者、非用户或家庭权力访谈，故整个机制保持条件性，不声称试点已显现这一趋势。

| D5 扩展设备形态 | 部分替换为 C2 | 从更万能的车转向分离移动、交接与专用处理；严格保留新增能力条件。 |
| D6 检查名额经济 | 降为所有需扩张分支的条件检查 | 不能把财务占比误当实际瓶颈证据；不独立宣称一个已被证实的新经济。 |

展开四条路径。它们可能重叠，也可能只在不同居民群体中成立，不构成互斥世界。下一阶段分别写必要条件、替代供给、反馈、拒绝和可区分的观察。
