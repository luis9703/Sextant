# 03 · 首次发散，研究前保存

**合成封闭世界；以下都是候选假设。** 本文件在读取研究参考与开展系统材料复核之前保存。不代表优先排序，也不预先确定最终保留哪些路径。

| ID | 改变的假设与候选机制 | 家庭／关系／资产可能变化 | 最该查的条件 |
| --- | --- | --- | --- |
| D1 | 从家庭独占设备变成家庭把不用时段交给运营方。 | 家庭把设备视为兼有自用与出租功能的物件；可能反过来安排家务去迁就外部需求。 | 家庭租赁供给能否获准、谁负责维护和事故、自用与需求是否错时、是否真有可分配净收益。 |
| D2 | 免去一项杂务后，人不只追求多做工作，也可能重新选择什么值得自己做。 | 家庭保留喜欢的挑书、散步，交出不喜欢的往返；新的家庭分工围绕偏好而不是谁更有空。 | 控制权归谁；“省下的时间”是否被其他义务吞掉；被照护者是否能自己决定。 |
| D3 | 社交损失引发选择性拒绝；居民要求保留有人的接触节点。 | 上门配送与共同取书并存；图书馆的相遇价值可能更明确，也可能因到访减少而难维持。 | 谁愿意到场、谁承担人员和空间成本；保留接触是否只是口头偏好。 |
| D4 | 家庭追求稳定完成任务，而不一定想拥有一台机器。 | 社区以共享时段或服务资格组织供给；资产集中持有，家庭保有可调用权。 | 稀缺时段如何分配；未持有设备者怎样获得资格；共同规则能否被接受。 |
| D5 | 抛开当前“小车”外形，把功能理解成“把物品送到所需位置”。 | 未来设备可能换格、换模块，或与楼栋接驳空间配合；家庭不必每家存放完整设备。 | 新形态需要哪些未验证能力；谁处理最后交接；是否只是把劳动转移给邻居。 |
| D6 | 当设备数量增加，关键资产可能变成得到检查与调度资格的机会。 | 家庭争取的不是机器本身，而是可用名额；社区组织可能围绕检查、故障和排队形成。 | 检查到底是否瓶颈；排队来自检查还是调度、需求、设备可靠性；怎样识别而不凭支出比例猜。 |
| D7 | 使用机器成为身份与归属选择，而不是统一进步方向。 | 有人自豪于亲自跑腿或互帮互送；也有人把免去依赖邻居看成尊严。双方可能合作，也可能给彼此贴标签。 | 哪些具体居民会这样理解；自选访谈能否提供线索但不能证明普遍心理；拒绝者是否仍有服务入口。 |

两组结构类比作为思考工具，不是外部经验事实：

1. **有限物品借用的排班关系 → 机器人时段分配。** 对应的是同一资源不能同时兑现两个占用承诺，因此使用权可与所有权分开。断点：机器人还涉及现场移动、故障和获批运营责任，不能只凭一张预约表运行。
2. **共享空间中“路过而相遇”的关系 → 图书交接节点。** 对应的是完成实用任务的路径可以顺带创造会面机会。断点：把人聚在一起不会自动形成信任，行动不便者也可能承担额外负担。

待研究材料：S1 的付款与收益区别、S3 的责任和所有权区别、S4 的分母与瓶颈判断、S5 的偏好异质性及同峰冲突，尤其关注能打开新候选的组合，而不仅删除不成立的收入故事。
