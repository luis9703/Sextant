# 问题与范围
原问题：现在我抛出一个问题，当AI大模型及其相关工具如此强大之后，像office、WPS这样子的软件还会有市场需求吗，尤其是现在大家都在用HTML格式去进行信息的传递和呈现。
目标：探索未来办公需求、产品形态、付费关系；不作投资判断。地域：中国知识工作为主，全球产品为参照；不把中国等同全球。截止：2026-10-02。近程2026—2029用于迁移，中程2029—2033用于条件路径，远程不定年用于制度变化；均非日期预测。
默认deep；约20分钟工作边界覆盖前六阶段及中性包，不要求用完。Skill目标50000—100000 tokens仅配置包络，实际输入、输出、缓存、推理计量均unknown。没有安装、发布、外部消息、用户设置修改或嵌套代理。
范围歧义：Office可指桌面编辑器、格式生态或M365组织服务；HTML可指静态单文件、托管网页或有权限数据后台的应用。分别探讨编辑需求、市场收入、厂商归属。用户说大家都用HTML是局部观察，不能作为普及率事实。
方法资源：仅冻结Skill及内部资源、实际网络原始来源；无项目历史与例子。
