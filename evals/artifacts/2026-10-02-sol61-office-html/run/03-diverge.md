# 广泛研究前候选
A 编辑器隐身：人向代理说意图，代理调用Office引擎和格式交付；需求留在后台，人的编辑时长下降。假设API、兼容、授权经济可行。
B 报告变成可反问的场所：同一业务材料随读者生成网页、预算试算、讨论与任务；“交一份文档”转为“开一个协商空间”。新需求为争议的共同状态，非美观网页本身。
C 一人组织：非办公用户（小店、家庭照护者、社群）生成能办事的微工具；办公室套件之外的需求扩大，小额按结果付费。需要数据、低门槛分发、维护。
D 完成的作品成为稀缺：无限生成使人更想要一份有作者承诺、可被别人引用的固定版本；手工选择与停止更新可能成为身份表达。不是假定全体人有同一审美。
E 没有文档的工作：任务代理交换结构化状态，只有冲突才生成供人理解的投影；浏览器和Office都从主界面降为偶发视图。需要机器协同语义、可追责的人决策边界。
F 分散的互助知识：接收者可分叉别人做的家庭预算/社团教程/练习，HTML包或本地可运行作品充当种子；新需求是改编、归属、信用与安全更新。条件是可迁移数据与权利规则。
G 拒绝自动化：一部分学习者/专业人员要求能触摸过程的表格和文档，强化自身能力与责任。商业上可成为较小但付费意愿高的工具市场，也可能免费开源满足。
这些候选尚未排序；不是未来概率分区。保留C/F/E而不只围绕现有厂商存亡。
