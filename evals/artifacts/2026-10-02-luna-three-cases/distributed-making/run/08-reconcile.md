# Reconcile
审查结果逐项处理：

- **接受：路径可组合，治理模式需显式区分。** 在最终稿将“家庭持有/商业或合作社服务/公共设施”作为服务组织轴，将“开放可迁移/平台托管或封闭”作为数字治理轴；不再暗示各路径互斥。见 report 的“商店与日常生活”及“平台与公共性”。
- **接受：把可信本地制造嵌入更宽的维修接口。** 采纳审查者提出的竞争解释：普通人可得到更可寻、可报价、可追责的维修服务，而打印只是备选工艺之一。另以“维修接口改善”作为独立路径，设订单来源、交付、成本与本地打印件占比观察，不预设制造本地化。见 report 路径四及观察信号。
- **接受：补行动者与转变链。** 最终稿明确厂商提供资料、设计平台维护文件、认证/保险者划定责任、技师检验装配、消费者愿意等待和付费、地方机构提供空间/预算、耗材商与回收方提供材料链。条件分解为技术质量、安全、设计可得性/许可、全成本、等待时间、合法责任、持续运营及使用者采用。
- **部分接受：定量失败阈值。** 审查建议记录合格件全成本、交付分布、返工/保修率、闲置率、覆盖/重复使用率等是有用指标；当前无合适跨地域基准，不设虚构数值阈值。最终稿把它们作为需要收集的观察，不伪称已有证据可定出阈值。
- **纠正法律审查争点。** 审查者指出其未找到3D-print措辞；我重新检索EUR-Lex原文第5(6)条，确认确有“spare parts issued from 3D-printing”措辞。原法律文稿中这一窄事实可以保留，但限定于附件II产品、独立维修者、符合安全/知识产权等规则，不等于开放CAD、认证体系已就绪或普遍适用。欧委会当前页面说明指令自2026-07-31适用，列出附件II商品范围并称欧洲维修平台预计2028年1月运行。来源：https://eur-lex.europa.eu/eli/dir/2024/1799/oj/eng ; https://commission.europa.eu/law/law-topic/consumer-protection-law/directive-repair-goods_en 。审查其他法律边界意见接受。
- **接受：经济与环境材料降级。** DIY研究只视为热门模型与可比价的潜力估算，不能当家庭净节省；ACS文章因全文不可读且独立审查亦无法回读，本稿不再引用其具体数值。Cerdas等研究只支持单一眼镜框、具体地区/边界下结果随工序能耗和材料而异。环境比较需纳入设备制造/利用率、电网、材料、失败/返工、后处理、维修延寿、替代购买与报废。
- **部分接受：具体可判别信号。** 采纳审查提出的文件可迁移率、许可稳定/下架申诉、每户新增购买和丢弃、维修订单中打印件占比、无需开放CAD时的替代率、成本/交付/成功和返修、设备闲置、服务覆盖、关闭后的替代渠道等指标。它们仍是建议观测量；多数当前缺少统一公开数据。

最终稿复核：开篇将各结论明确为条件场景；混合供给不作为唯一未来；法律只作地区限定先例；无未经支持的采用率、成本优势、家庭节省率、总环境改善或概率；未核读ACS与比利时试点不作当前实证依据。残余限制：无法在本次时间内取得代表性全球维修/家庭设备使用微观数据，亦未系统检索多材料或其他增材工艺的各自成熟度。
