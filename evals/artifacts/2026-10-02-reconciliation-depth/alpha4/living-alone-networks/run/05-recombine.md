# 05 Recombine — post-research candidates

1. **分户的选定亲属网络（refined from nearby chosen kin）**：继承初始候选1与3。第七次人口普查说明一人户是一类住宅户，不说明支持网络；CHARLS既有研究材料提示非同住子女仍可支持父母。新的重点是近距离或有固定联络节律、但保留独立住宅的“连续性”，可由亲属和朋友共同组成。改变的是把持续互助的依赖从共同住址转到稳定接触与可替补角色；后果是关系网络仍能照料，但脆弱点转为搬家、失能和照护分配。
2. **私门后的轻量公共层（refined/replaced from shared infrastructure and reciprocity ledger）**：继承候选2、5。短期 pop-up city 研究提出共享日历、低门槛发起活动、轻量身份/信任脚手架可促成自组织。改变依赖：不预设居民要长期共居、共享财产或把照护换算成积分；只需楼内/街区有自愿参与的小型公共活动、求助入口和明确隐私边界。新后果是平日一起吃饭、接包裹或散步可能积累成可求助关系；若账本或排名替代了关心，或组织者透支，则会转向退出和冷漠。
3. **可问责的社区服务网（elevated from market/service-layer candidate）**：继承候选4、8。官方政策已经鼓励居家、物业、专业照护和社区服务协同，但只是方向；老年独居样本呈现社会支持/基层医疗连接缺口。改变依赖：不要求朋友扛专业照护，明确专业服务的合同、转介、紧急升级和公共补贴。新后果是单身者能用服务获得稳定日常功能，但“服务到位”未必带来情感陪伴；成本或质量不足时，家庭/志愿者仍成最后兜底。
4. **独立生活的分层与回摆（expanded failure branch from candidate7）**：保留候选7，吸收研究的服务缺口。若住房、工作和健康资源不同，独居可能是选择，也可能是被迫不稳定的租住；较富者购买可替换的服务和活动，脆弱者则在独住、合租、返家间摆动。这个分化改变社区路径的受益对象，提醒不应把“独居者的选择”推广给所有人。
5. **机器陪伴仍属窄支线（candidate8 downgraded）**：目前证据仅支持政策鼓励监护/慰藉类智能产品，未查得可靠的人机陪伴能替代人际照护的结果。保留为提醒、联系与异常上报的辅助；若讨论情感或身体照护只能明确标为远端假设。

现有基线对比：分户亲属支持、助老服务、短期共居/活动组织、意定监护均已有讨论或制度实践。本轮新增关注的是这些已知功能如何串成普通独居生活的持续性：联系的节奏、互助角色的替补、退出规则与专业服务接手。没有据此主张社会首次出现“选定家庭”或共居。
