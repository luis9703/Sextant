# 02 Foothold

截止按2026-10-02。先把“一个人住”作为居住户规模，不把它等同于婚姻状态、偏好、孤独或关系网络。

- F1（已核实，官方普查表）：国家统计局第七次全国人口普查家庭户表列示，2020年全国一人户58,396,327户，全国家庭户401,934,196户，约14.5%；城市一人户23,099,057户。来源为普查表，单位是户；它不说明选择原因、持续时间、婚姻状态或亲密关系，也不是2026现状。链接：https://www.stats.gov.cn/sj/pcsj/rkpc/6rp/html/A0501a.htm （访问2026-10-02）。
- F2（已核实，官方法律文本）：《民法典》第33条允许完全民事行为能力成年人事先与近亲属、其他愿意担任监护人的个人或组织协商，书面确定失能时的监护人。支持了“非配偶可承担一项正式照护/代理角色”的制度可能性；不等于广泛授权朋友共同决策、财产共享、继承、医疗全部事项或自动建成互助社区。链接：https://www.court.gov.cn/zixun/xiangqing/233181.html （访问2026-10-02）。
- F3（政策方向，不是效果证据）：国务院办公厅2024年银发经济意见提出拓展居家助老、社区助浴、助餐、陪护等服务主体；官方发布的2024年末公报摘要称社区养老服务机构和设施36.6万个。它显示服务可由社区/专业机构补充亲属照护，但未测量覆盖、公平、质量、稳定性或单身者的可及性。链接：https://app.www.gov.cn/govdata/gov/202401/15/511180/article.html ；https://www.dhlc.gov.cn/czz/Web/_F0_0_69TZZV06CAE57ACA879642D18F.htm （访问2026-10-02）。
- F4（未核实，故不使用）：媒体转述“单人家庭户超过一亿、2030年1.5–2亿”的说法，本轮没有找到可直接对应的官方原始统计表及口径，不将其作为事实或趋势数值。

主要未知：城市与县域差异；“主动独居”和因迁移、丧偶、租住等而独居如何区分；实际陪伴频率、紧急照护可达性；一人户与婚恋/生育的关系；非亲属签署协议后的信任、履约和争议解决；政策服务是否进入普通社区且可负担。没有用户所在城市资料，所有微观生活场景需保持条件性。
