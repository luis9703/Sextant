# Frame

问题：如果越来越多不懂编程的人能借助 AI 做出小工具，未来十年软件、工作分工和公司形态会有哪些不同未来？

意图：展开可比较的未来路径，而非预测单一结局或给投资判断。

范围：以全球可联网的知识工作和小型组织为主，兼顾大型企业；时间窗至2036年；信息截止2026-10-02。这里的“做出小工具”先视为用户报告的现象，需区分原型、个人使用、生产系统与规模化产品。“不懂编程”指没有系统的软件工程训练，不等于缺乏领域知识。

配置：deep。资源限制：约15分钟用于前六阶段及中性审查包；宿主未提供token计数，实际使用unknown。无新增依赖，产物限定本临时run目录。

假设：用户想象工作的结构变化。软件安全、数据权限、持续维护和责任承担可能成为比生成代码更显著的约束；这是待检验假设。
