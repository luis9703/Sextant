# Diverge: first pass before broad research

候选只记机制，不做概率或精致故事。

1. **领域人自造/自改软件**：一线员工直接把隐性流程写成小程序，减少需求排队；瓶颈转向谁有权连接数据、谁为故障负责。潜在人性收益：掌控感、表达专业判断。
2. **软件从“产品”变成可临时生成的工作界面**：用户不是挑选通用SaaS，而是每个任务现场拼出临时工作流；若上下文可携带、结果可追溯，组织界面更像可编排材料。失败点是上下文丢失、重复和维护。
3. **工具洪水与平台围栏**：易造让每个团队有定制工具，组织随后为权限、审计、整合和支持建立平台门槛；能力下放与控制集中同时增长。
4. **公司缩小，外部能力按需组合**：AI降低启动软件服务的前期团队规模，小团队以专业知识+生成工具服务窄市场；信任、销售、责任和客户获取仍会促使联盟/中介出现。
5. **拒绝软件化/共同维护**：员工可能选择纸面、共享模板或流程简化，不愿将判断交给脆弱自动化；AI降低造软件成本也会让“先造一个”更诱人，产生反向的维护负担。社区/工会式共同治理可能替代企业内工具所有权。
