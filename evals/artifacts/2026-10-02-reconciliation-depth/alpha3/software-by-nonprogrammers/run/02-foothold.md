# Foothold

- 用户提供的观察：“越来越多不懂编程的人也能借助 AI 做出自己的小工具”。当前视为观察报告，未获得用户的样本、地区或工具定义，不能推断普及率。
- 早期专业开发的真实任务结果并非一律提速。METR 对16名资深开源开发者、246个成熟项目任务的2025年随机试验发现允许当时AI工具后完成时间平均增加19%，但作者明确说不代表大多数开发者/工作；2026年后续更新报告有可能加速的迹象，同时选择偏差和计时可靠性使证据很弱。[S1](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/) [S2](https://metr.org/blog/2026-02-24-uplift-update/)
- 美国BLS 2024–34预测软件开发者就业增加16%（+267,700），这是美国职业预测，不是AI因果效应或全球结论；它提醒不能把“更多人能生成工具”直接等同于软件工作消失。[S3](https://www.bls.gov/ooh/computer-and-information-technology/software-developers.htm)
- 边界：代码产出速度不等于可维护、合规、互操作或安全部署；初学者可做个人工具，也不自动意味着其能接管高风险系统。当前三项都缺直接、广泛的非程序员生产部署证据。
