# 07 — 独立审查

审查对象：指定中性审查包；信息截止日按包内要求取 2026-10-02。只读该包及其列明的六个来源，没有查阅生成历史、项目文件、其他测试或旧评测，也没有使用包外材料。本审查是证据与情景结构的挑战，不是对未来的预测。

## 结论

候选路径写得较克制，且多数条件句能避免把当下信号说成远期定论。最值得保留的是“生成速度可能快于理解、验证、集成和维护能力”的张力，以及把业务所有权、工具寿命、全生命周期成本作为可观察区分信号的做法。当前证据支持这些机制值得追踪；它还不足以在 2036 年的组织形态间作选择。

有两处材料需要按截止日和来源原文更新。包称 BLS 预测软件开发者就业在 2024–34 年增长 16%；当前引用页标明最后修改于 2026-08-27，给出的预测期已是 2025–35，软件开发者为 +10%（含软件 QA 与测试人员的合并职业类别亦为 +10%）。这是美国职业预测，不能识别 AI 的因果影响；可保留“并非职业消失的直接证据”这一边界，但不应沿用 16% 及旧预测期。[BLS 页面](https://www.bls.gov/ooh/computer-and-information-technology/software-developers.htm)

Anthropic 页面摘要段写创业相关对话 32.9%、企业相关 13%；页面详细分析段则写 Claude Code 中创业相关 32.9%、企业相关 23.8%，Claude.ai 中企业相关 25.9%。页面把用户项目类别明确称为基于有限上下文的推断；样本也排除了 Team、Enterprise 和 API 使用，且没有测量最终代码如何落地或改善生产力。因此“创业 33% 高于企业 13%”并非稳定的同口径证据；应指出页面内部数值冲突，避免据此推出组织采纳差距，更不能推出小团队成功或公司规模变化。[Anthropic 分析与限制](https://www.anthropic.com/research/impact-software-development)

## 情景挑战

五条路径有启发性，但不是同一层级的互斥未来：A 是组织控制与平台治理安排；B 是工具生命周期/交互模式；C 是供应商结构；D 是共同的成本压力或失灵机制；E 是所有权与集体治理形式。包已声明路径可以重叠，这一点是对的，但读者仍可能把五者误解为覆盖未来的五种完整状态。建议给每条路径标注“主要变化对象”并说明组合关系；尤其将 D 写成可跨 A/B/C/E 发生的机制，避免把它和终态结构并列当作独立形态。

还有一项可能改变组织图景的遗漏：业务人员可以生成工具，却不一定拥有、运营或控制它。宿主软件商、云平台或企业 IT 可以把生成能力嵌入现有工作界面，统一持有数据、权限、运行时与责任；员工只描述或微调流程，工具既不是独立员工资产，也不一定是一次性应用。这种“平台代运行、员工参与定义”的未来可能同时包含 A 的治理与 B 的按需界面，却把供应商权力和企业内控制权推向中心。它是条件假说，不是已观察到的趋势。区分观察可以是：生成资产、运行日志、数据和故障责任分别归谁；员工可否导出、转移或独立运行。

各路径仍缺少“什么算成功造出软件”的共同门槛。原型、低代码自动化、内部生产应用、面向客户的产品和安全关键系统风险与维护承诺差异很大。若不按风险、是否持久运行、数据敏感度与外部用户分层，A 的“生产所有者”、B 的“短时生成”和 D 的“全生命周期成本”就难以比较。观察指标应跟踪从试验到获批上线、持续维护、复用或退役的完整漏斗，并报告分母和风险层；仅统计生成量容易把一次性原型当成生产能力。

另一个待检验的竞争解释是，低成本生成会增加过去因成本太高而未被满足的软件需求。应用数和维护工时因此可能同时增加，但这不必表示每个功能更贵、工程效率更低，亦可能是组织开始自动化更多边缘流程。D 的判断最好明确区分“单位质量/风险调整后的功能成本”和“总维护负担”，并记录未解决需求、净减少的手工步骤及故障影响。反过来，工具减少也可能来自流程统一或业务需求不再值得满足，不一定是 AI 不好用。

E 的条件列得合理，但“共同拥有”需拆清法律产权、可操作控制权、数据权利、维护出资、退出迁移和事故责任；其中任一不清，可能使共享工具实际依赖单一维护者。可保留 E 为弱证据下的探索性候选，并把上述治理条件作为观测问题，而非暗示已有可复制的协作案例。

## 可保留与待改表述

可保留：METR 两轮研究衡量不同工具期与选择机制、适用范围有限；Microsoft 指南展示一种企业低代码治理做法；arXiv 预印本揭示两类低代码工具在问答讨论中的生命周期差异；非专业开发者生产应用的可比长期基线不足。上述都是对来源类型、测量范围与外推边界的描述。

应更新：BLS 的预测期和数值；Anthropic 的企业占比及其口径。应收窄：把 Anthropic 对话构成用作“早期供应商观察”，不能作为真实企业与创业公司采用率。建议补明：五条不是完整且同层级的选项；生成者与资产、数据、运行责任拥有者可能分离。此处新增解释均为竞争性假说，仍待观测，不应写成事实。
