# Second divergence — material changes after research

不是给第一轮补来源。下面改变约束、行动者与因果机制；所有未来内容仍是条件假说。

## Mechanism comparison with names removed

1. 技術释放 → 组织授权改变 → 知识持有人能直接说话与验证承诺。
2. 中介可编辑 → 双方选择/监督翻译人格 → 关系规范改变。
3. 接触产生关系 → 新学习动机 → 从通用考试投入转向具体人/事的能力。
4. 社区掌握数据与访问规则 → 公共入口与概念控制 → 小语种参与权改变。
5. 搜索与交流边界扩大 → 推荐和注意力竞争 → 跨国同质圈或差异共同体。
6. 顺滑翻译失败或被主动关闭 → 共同实践的多模态语言 → 新身份与可退出空间。

这些机制可并存，但替代中心不同：组织治理、同意、动机形成、集体所有权、匹配制度、共同实践。全部“更便宜所以更多交流”不能代替它们。

## Added, replaced, refined

- A → P1：放弃“英语好的人失势”的单向结果。新分支是现场人直连提高议价，另一分支是平台扩大雇主选择并压低稀缺租金。S1/S2 只支持接口可用，组织权力变化仍条件。新瓶颈是证明能力、授权、支付与承担责任，而不是翻译自动解决一切。
- D → P2：从“人格替身摧毁真实性”转为翻译边界成为关系契约。S4 允许正向协调与负向怀疑同时存在，也提醒不能把一次文字实验外推亲密关系。新增可保存分歧与原词的翻译形式：朋友愿意听陌生说法，减少自动正常化。
- C → P3：原来“语言学习变奢侈仪式”不足以覆盖就业、身份、教育和安全。改为混合需求；先有跨语关系，再学对方的局部语言；学校可教授调解、修复与原文检查。S5 是既有框架，不证明政策将采用；变化需要考试与聘用激励，不能靠教师换课程名。
- E/G → P4：从个人翻译工具的语种覆盖，改为社区掌握转译入口。S6 是转写治理先例，开出“市场/图书馆/地方社群提供翻译并共同决定哪些内容不被外部收录”分支。技术和财政未验证，所以保留条件；不假定社区意见一致，也保留少数成员的退出与异议。
- B → P5：把“兴趣相同而更同质”发展为匹配制度岔路。翻译只扩大可选择集合；平台按停留时长、冲突或共同任务分配机会会形成不同圈子。没有平台行为证据，故作为竞争机制，不预设算法一定伤害人。
- F/H → P6：不把失败仅当风险。即使完美翻译也可能不替代共同发明的词、物件和沉默；某些关系把翻译当临时脚手架，撤去后形成共享实践。另一分支主动限译保护亲密，但可能用于排外。S3 延迟与上下文权衡只是设计线索；“共享语必然诞生”取消。

## Retained unfamiliar possibilities

公开论坛支持“原词保留并附解释”而不是全译成接收者熟悉框架；一次交流可以故意保持陌生。非个人付费形态保留：公共翻译点、社群共用设备、视觉/文本替代渠道。它们所需治理和持续维护成本与耳机普及不同，不能共用同一必要条件。

未开发候选：翻译与跨境政治运动、法庭解释权、医疗手语等高后果路径，因本轮证据与时间不足。未淘汰其可能性；交付应如实留下范围限制。
