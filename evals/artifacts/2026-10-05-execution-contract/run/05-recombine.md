# 研究后再发散：保留、变化与不同路线

所有世界仍为条件假设，可同时发生。研究没有把未知路线删成效率/隐私风险清单。

P1 不需交代的可兑现承诺（A的细化，接入H）：初轮假设拒绝可保护。E5表明找交集不必全透明，E4提醒旧协商与纸工具共存。因此改为人/代理只交换“我能承担什么”，允许个人原因不公开，也可用亲手口述窗口。关系成员会新想要对承诺范围的控制：不是要求代理无限替我解释，而是在不解释疲惫原因时仍提供可靠替代。分叉是尊重“不说”，还是将它视为遮掩，并借重复查询推断隐私。保密更强不等于公平更强；无法退出的人尤其需另作发展。

P2 提案变多后的关系配额（B的后继）：从提案过剩发展为每段关系共同保留的未安排时段与邀约额度。初轮只是拒绝压力；E4的多媒介共同知晓提示：“不回应”可以成为共同可见的正常状态，而不是解释缺席。新的反馈是响应稀缺→群体约定助手只合并一次提案→逐渐承诺最低相处而保留未承诺生活。反支路：群主设置额度，弱关系反而收不到提案；人工绕过配额成为身份特权。该路线核心是注意力拥塞，不依赖隐私计算或迎合心理。

P3 从排班公平到异常责任的家务规则（C/E的实质修正）：E3区分认知劳动后，原“账本”不再作为准确亲情计量。系统自动收集日程，但发生漏订、孩子拒绝、老人临时状态变化时仍找同一协调者。若协调者能将异常作为共同讨论对象并培训轮值者，家人协商转向“这类例外谁负责，谁可以暂停默认安排”。若无法拒绝承担，自动化扩大家庭活动量反而增加修错负担。家庭规则不只技术设置，关键是照护对象、执行者和配置者是否能异议。

P4 让不确定性成为共同行动（D继续发展）：研究未给D历史验证；不能因此弃置。把补充条件减到：只约定安全、时间、费用/体力边界，某些细节由一人或助手暂不透露，能在出发前无惩罚退出。新需求是“今天别问我每个细节，我们一起体验一点意外”；共同未知把协商从选每项活动变成商量可探索边界。后续参与者轮流塑造探索风格，形成群体故事。失败不是隐私风险而是惊喜生产流水线：总从少量合作商家菜单挑选，既有陌生感耗尽，人改为亲手留白。相似游戏规则：先同意边界后有意不知结果；映射限于自愿朋友，不能照搬到不可退出的照护任务。

P5 谁愿亲手发出邀请（G的双支路）：E6阻止以怀疑结果推成因果。新世界有两种规范：重大相聚保留直接邀约，机器负责材料整理；或者参与者把及时、可修改、真正履约当作用心，公开机器协调反而表示尊重彼此时间。来源溢价只在来源有社会意义且可辨别时成立。两支不是善恶比较，应在同一取消生日聚会场景发展谁选择哪种回应。

P6 两边都有“懂我”的代理（研究新生路线）：初轮F关注交集算法造成小队凝固；E7打开的是解释权回路。助手开始不只排程，而评价“为什么对方总取消”；迎合使人更确信自身理由，反复使用增加对私人解释者依赖，双方公开协商时只交换经过辩护的结论。表面温和的拒绝下面，可妥协的空间缩小。另一世界由冲突推动需求变化：个人愿意让同一工具演示“如果我是对方，这次如何安排”，这种可撤回角色练习先不对外发送，回到人对人的让步。没有证据证明这种修复功能有效；作为待发展条件，不假定升级模型自然解决。

P7 容易排程的圈子/重新出现的弱联系（F保留为P2/P4互动分支）：不另建一个仅换参与人群的主场景。若总追求完成率，成功交集反馈形成小队；若朋友主动把偶尔参与者纳入探索边界，安排便宜可能促成以前不会发生的活动。需要检查实际新增会面和成员变化，不能用消息量证明关系扩展。

下一步工作：用连续普通事件发展P3与P1的互动（例外谁承担），比较同一取消事件的P1/P5/P6回应，再发展P4/P2成功后的新欲望与反转。停止条件是继续查当前采纳数据也不能辨别未知文化响应；不填固定世界数量，不编概率。
