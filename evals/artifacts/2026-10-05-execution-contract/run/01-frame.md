# 范围与临时种子

原题：如果语音助手开始能代人整理和提出日常安排，未来十年家人和朋友之间的协商会怎样变化？

范围：2026-10-05至约2036年；以中文生活场景中的家庭照护、共同居住、朋友聚会为具体入口，但不推断某国普遍人口行为，也探索跨语言、跨平台和拒用者。协商包含谁提出、谁解释理由、谁拒绝、谁承担后果，以及关系意义，不只找共同空档。探索模式deep；首次阶段以宿主约25分钟为边界，后续审查另由宿主直接启动。资源：冻结包、Python标准库、可用网页查询与阅读；不调用私有日历或联系人，不安装依赖。实际token计量未知，规划token目标不是最低消耗。

用户给出的是假设能力：可整理并提出安排。尚未支持其能可靠理解所有人的隐性偏好，代表不同人谈判，跨平台执行，或得到家人同意。

查源前种子：把混乱口头意图转换成可讨论的提案，会降低提出一个选项的难度；也可能让“谁愿意为我们费心”与“谁安排成功”脱钩。语言界面能让原先不愿写日历的人参与，但语音可达不等于社会授权。助手提出的是“有人提出的安排”，还是无人负责的机器建议，会改变拒绝的代价。

 consequential unknowns：已可用的只是单人提醒/日历还是主动提案？家庭数据是共享还是各自保留？是否只在明确同意后执行？说出口的愿望是否会错误变成承诺？这些边界只做定向事实检查；关系未来留给随后发散。
