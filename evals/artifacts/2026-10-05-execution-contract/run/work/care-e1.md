# 连续事件：排班成功之后谁处理不顺利

本工作是概念探索，下面人物与事件均为虚构示意，没有模拟数据。暂时成立的条件：整理日程足够可靠；各人只交出可承担窗口；照护对象能通过语音/纸确认提案；不会自动执行未经确认的高风险事项。未假设系统能测出所有情绪或照护质量。

事件一：三名成年手足每周分担父亲探诊与采购。原协调者小薇过去打电话询问所有人，助手现在能提三份候选表。小薇选一份，哥哥说“以后不用你这么辛苦了”。父亲却告诉小薇，他不喜欢这次陪诊的人，因为对方总急着走。可行时间与可接受照护首次分离。系统表格全绿，小薇仍需私下听诉、改安排，担心公开理由伤哥哥。

事件二：下一周父亲临时想去看老朋友，刚好撞上弟弟已确认的陪诊时段。弟弟不愿解释为什么不能延长。小薇以前会自己接手；在新安排里，她请求代理展示“当前无人承诺的部分”，而不披露弟弟私事。哥哥看见候选安排没解决的空缺，接下陪父亲访友，但拒绝随后两次采购。家人开始协商任务组合与回退安排，父亲也明确某些事可以推迟。变化来自例外被共同看见与有人能拒绝，不能归因于提案算法本身。

事件三：几轮后，家人每轮选择一个“异常接手者”，其他人把适用的注意事项口述成可修改的提示。小薇的知识逐步变成共同可用的资源；她不必永久当事故热线。哥哥后来承担接手者才发现预约成功不代表父亲愿意出门，提出将探诊前电话也计入任务。大家争的单位从空档变成完整责任段，连事前安抚与事后追踪都可被要求说明。父亲在休息日口述“别在今晚提醒我任何事”，不再只是排班对象。

重复使用反馈：能被拒绝的异常任务→轮值者学习→默认提示改进→原协调者可暂停→更多成员有能力提出安排。家庭中的“会操心的人”身份可能变成可学习的角色。小薇或父亲也可能不愿把关心写成模板，保留一部分无记录的陪伴；这并非系统失败。

反向分支：若小薇不能拒绝，哥哥的“省心”会带来更多活动提案，所有例外依旧转给小薇，表格产出越多越遮蔽她的修复劳动。另一分支是父亲不能异议，家人把他的拒绝归为“不配合”，安排效率提高但主体性下降。再一分支：家人争论投入量后改为不留贡献记录，只保留谁负责完成并允许提出不足；公平不能只依赖账本。

回到现在的桥：先由自动提案替代抄材料；数轮可见失配之后，参与者承认“没有承诺”与“必须协调者补上”是不同状态；之后才可能讨论例外轮值。共识与可拒绝权是社会条件，不能由设备更新直接提供。扩展到长期规则需经过不同异常，不应在一次满意排班后宣称分工已改善。

与保密承诺的冲突：隐藏原因减少解释压力，也可能不让别人知道照护对象的不舒服。解决方向是允许本人选择“本次方案不可接受”但不逼其披露理由，并提供人工联系；如果无足够安全表达条件，P1无法靠技术保证。高控制家庭中应把无法退出作为独立停滞条件，而不是继续假设自由选择。

需要继续观察的问题：本探索已说明例外的反馈，但现实中“原协调者成功暂停以后别人是否接得住”需要长期家庭观察，未有本次数据。将其保留为辨别P3转型与负担转移的观察点；不再写第二个同类虚构家庭来代替证据。
