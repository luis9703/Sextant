# 连续事件：可以安排的共同未知

以下是虚构示意，非预测日期/采用率。临时假设：朋友各自给出可参加窗口、活动/花费/体力边界；提案能尊重它们；允许不解释地退出且仍有资格参加以后活动；未知内容不涉及安全、医疗、财务等高风险决定。不要求全面行为监控，也不要求外部机构批准。

起初：四名朋友往常在群里反复发餐厅链接，最后总去同一家。一次他们对助手说“周末两小时、室内为主，留一个我们没预先看过的部分”。它给共同窗口，不立刻公开全部细节。到场后其中一人拿出旧照片，另一人选了一条附近可走的路线。新用途不必是购买服务；朋友贡献未公开素材也能成立。

第二次：大家开始不满足于“助手懂我喜欢什么”。一位朋友说“请不要再按我过去点过的东西选，我想试试你们喜欢的”。协商的目标转成谁可以为大家保留一点未知，谁的风格本轮值得信任。边界有意稳定、内容轮流变化。群体形成某个成员策划的故事而不只形成一致偏好。助手整理了现实条件，朋友承担的意义劳动反而更显眼。

第三次：成功后，两名很少出席的旧朋友加入。可行窗口筛出他们各自只适合某些活动，群里先做两种小活动而非硬凑全员大聚会。朋友关系从只有全员才能成立，转成某些成员暂时相遇但仍保留共同故事。若轮流邀请旧友，工具使原先没动力安排的短时联系可发生；如果只优化最快凑齐，旧友会再被跳过，稳定小队固化。因此“多见面”不能自动推成“交往半径扩大”。

第四次：每个成员都可以随口提，助手在空档产生过多邀请，原先惊喜现在像响应工作。几名成员设置“本月只接收一次合并提案，别为所有空白找事情”。协商开始保留两个资源：可安排的共同时间与不可安排的私人余地。新需求是被留下、不被随时动员。若群体尊重它，邀请额度成为低冲突默认；若忙者退出而高响应者一直相聚，小队分化加速，选择机制更偏向易协调者。

第五次：商业推荐占据惊喜菜单，每轮都是相似体验。朋友撤掉自动内容选择，只留下窗口和边界整理，轮流带一个不事先公布的小想法。失败打开另一未来：成熟自动安排并没有取代人策划，而使人愿意保护“不被预测的部分”。若成员只是想少麻烦且并不关心故事，他们可能接受重复菜单；这也是有效路线，不强求所有人发展新欲望。

反馈机制：成功探索→参与者愿意交出一点控制→产生新故事与轮流身份→更多提案→注意力拥塞→共同限制提案→人重新占有惊喜内容。并非所有步骤必经；在第二次就发生不舒服且不能退出，会直接返回全部明示计划。

从现时到这世界的桥：共同窗口整理先替代群聊比日期；有人首次请求不是最合偏好的选项而是允许变化；几次自愿成功后才会将边界协议化。后期约束需求来自实际提案增多，不是设备必然自动制造邀请。十年内能否扩散取决于可靠性、退出不受惩罚、文化意义及参与者想要探索，而不依赖虚构硬日期。

与家庭世界的差别：朋友可不参加，照护任务常不可不做，不能把无惩罚退出的边界照搬。家庭也可在低风险休闲中安排惊喜，但主体是共同参与者，不能由照护执行者强迫被照护者“接受惊喜”。

下一问题：现实中谁退出、谁仍被记为朋友，需要长期群体观察；重复写更多惊喜桥段不会解决。观察应区分提案数、实际相聚、重复成员、缺席者是否仍被主动邀请，以及私人余地是否变小。将这些进入综合路径。
