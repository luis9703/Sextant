# 规则权不平等后的新互助空间：审查后新发展

依据R7，暂假设共同账户只有一人能改共享规则，提案被其他人日常依赖；使用者无法平等改动，也不能轻易退出全部家庭义务。不是对当前厂商功能或普遍家庭的描述。

事件一：共享账户主人把“有空就接手”设成家庭照护默认，声称“系统算过了，应该你去”。他自己的私人空档不共享，系统解释只呈现别人的可行时间。其他人仍点确认，避免家里争吵；一人开始少说私人计划，另一个保留纸笔日程。可行时间逐渐不是愿意承担，却被默认当义务。

事件二：一位成员的静默设置被管理员重开，P2里的“不回应”失去共同边界意义。她与另一个成员私下约定：有时候可代接，但不要记入共享系统，以免成为下次可用能力的依据。共享表越来越完整，真实协商迁到私下电话与口头承诺。P1在共享系统中失效，仍在两人的有限承诺交换中局部存活；P3的全家庭轮值失效，但小范围替补仍可能进行。

事件三：私下互助积累了足够共同经验，他们不再为所有活动争规则权，而建立一份只共享愿意承担窗口的平行小表，有人用纸、有人口述。管理员发现信息不全，可能要求再登记，带来“谁的安排算正式”的冲突。成员可选择披露完成结果而保留过程，或直接争取“未登记不等于无效”。新需求从自动方便变成一块不被默认征用、不留完整轨迹的协商空间。

不同结局：若家庭有安全争议条件，平行实践显示替代可行，可能迫使规则权被重新谈判；若管理员能惩罚绕行，私下互助只小规模存在甚至终止，系统强化表面合规；若有人能独立生活，可退出共享账户，关系仍保留人工联系。不能把退出能力平均分给所有人。

朋友群的同机制有不同代价：群主允许熟人绕开配额，却要求偶尔来的人逐项确认，参与机会集中于核心成员；被排除者另组松散小群，使用更少自动化和更短承诺。群体可能扩散为多个互助圈，而不是所有弱联系都消失。朋友一般可不参加，但被退出者也损失共同故事与机会，不能将其当零成本。

核心因果：规则设置权→默认义务与不透明豁免→表面确认→私下绕行→新的小范围信任/信息空间→正式性争议或分裂。它不同于P6心理迎合，不需AI评价动机；也不同于P2纯注意力压力，不需更多邀请。没有规则权不平等或默认强制，不能把所有系统未来归入此路。

回到现在：先需要少数人配置工具、其他人依赖建议；再需要建议具有家庭判断的权威且成员不能有效异议。共享工具本身不是统治前提。若现有关系本就高控制，工具可能只是载体，应区别旧权力与技术使默认判断更不可见的增量。

观察：谁改规则、谁可豁免、哪些确认出于避冲突、出现多少未记录但真实完成的互助。不得为观察强取私下材料；当成员不能安全报告，结果不可测而非互助不存在。多工具共存也可能只是方便/离线，不能自动认定为抵抗。
