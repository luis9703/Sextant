# Sextant 评估方式

评估只回答一个问题：这个 Skill 是否让用户对未来的认识产生了**有支撑的增量**，代价是什么。文笔流畅、故事震撼、专家没有听说过，都不是充分条件。研究依据与设计取舍见[研究与评估设计](../docs/02-research-and-evaluation.md)。

**五种证据等级，互不替代。** 公开声明必须说明自己属于哪一级。

| 等级 | 它能证明什么 | 它不能证明什么 |
| --- | --- | --- |
| 打包验证 | 文件结构、引用路径、版本一致和安装行为正确 | 任何输出质量 |
| 完整示例 | Skill 在一次真实运行中实际做了什么、产出了什么 | 普遍有效，或优于基线 |
| 模型审查 | 另一个上下文对事实、条件和遗漏的检查结果 | 独立事实证据或专家判断 |
| 专家评估 | 领域内已有讨论的覆盖情况与条件是否合理 | 未来会发生 |
| 前瞻预测成绩 | 预先登记的可判定问题到期后的表现 | 宏大情景的想象价值 |

`results/` 中的验证记录只登记实际完成的测试，并标明每项结论的等级。没有做的事写"未做"，中断的事写"中断"。

**四个维度分别报告。** 一个维度的高分不能遮住另一个维度的严重问题。想象价值是主要研发目标，事实与机制是必要条件。

| 维度 | 怎样检查 | 初版可以声称什么 |
| --- | --- | --- |
| 事实与证据 | 抽查关键来源是否支持对应主张，保留条件、日期和来源家族 | 证据使用是否准确，不能声称未来已被证实 |
| 路径与机制 | 对照条件、行动者、欲望与身份、反馈、失败出口和竞争解释 | 叙事是否自洽且可质疑，不能声称因果已识别 |
| 想象价值 | 对照明确的已有认识，先评机制与条件差异，再评叙事；记录最相近的已有观点 | 相对于本次基线和评审条件的认知增量，不等于原创 |
| 预测表现 | 对预先登记且已结算的问题评分，对照同题基线 | 在已结算领域、期限和题集上的表现 |

**检查一个案例时逐项回答。**

1. 去掉新名词和修辞后，每条路径的机制是什么？
2. 相对于哪份明确的已有认识，它增加了什么：新机制、新条件组合，还是只换了包装？
3. 条件是否明示？在这些条件下是否暂未发现致命矛盾？
4. 对现在事实的引用是否真的支持对应前提？来源的限制是否保留？
5. 两次发散是否真的发生：研究后有没有新增、替换或撤回的候选？
6. 审查是否在没有生成历史的上下文中完成？处置和剩余异议是否记录？
7. 被淘汰的候选及其理由是否保留？
8. 虚构场景是否标记？数字、年份、概率是否有依据，或明确标为未知？
9. 观察信号能否区分路径？看到相反结果时判断怎样改变？

**新颖性只用有边界的说法。** 记录检索范围、语言、资料截止时间和最相近的已有观点，状态取"已有且常见""已有但本基线未覆盖""本次检索未发现直接对应"之一。最后一种不证明世界上没有人提出过。"每个案例至少一条新路径"不是硬门槛；成熟题目、证据不足或失实的种子可以没有合格的新增路径，这类零增量案例也要保留。

**对照实验的设计。** 相同问题、模型版本、资料截止时间和预算，比较三种方式：普通提示直接回答；给同一份整理后的证据但不用 Sextant 方法；完整 Sextant 流程。评审者不知道产物来自哪一组，展示顺序随机，多个读者分别评价并保留分歧。模型评审可以辅助筛查，不能作为唯一效果证据。初版 8 到 12 个跨类型用例只是调试试点，不能据此声称稳定优于基线。

优先检验三个设计假设：研究在前的顺序与两次发散相比怎样；新上下文审查相对同上下文检查增加了什么；带机制笔记与不带笔记是否更能产生增量。每次只改一个因素，使用不含答案泄漏的独立运行和保留案例。
