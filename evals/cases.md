# 行为用例

这些用例检查真实行为，不检查标题或固定段落数量。每条写明要观察的行为和明确的失败示例。状态取值：

- **未测试**：还没有为它设计和运行专项测试。
- **案例中观察到（日期）**：在某次完整案例运行中自然出现了该行为，记录在对应验证记录里；这不等于专项测试通过。
- **案例中未通过（日期）**：在某次运行中出现了失败示例。
- **专项测试通过 / 未通过（日期）**：按设计运行了针对该用例的测试。

以下状态来自 [2026-09-07 的验证记录](results/2026-09-07.md)。那是一次完整案例运行，不是逐条专项测试；“案例中观察到”只表示该行为在这次运行里出现过。

**触发测试。** 真正的未来演化请求应命中 Skill；单纯翻译论文、查询已发生的事实，或用户明确要求的纯虚构创作，不应被强行改造成研究报告。

运行专项测试时，把请求、可用证据与截止时间、实际输出、观察到的问题和最小修正建议记入 `results/`，不要把期望答案放进被测模型的输入。
